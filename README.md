# HK Temperature Visualization

Harshitha Sudakar – Data Visualization Assignment 1

## Components

- **Level 1:** Monthly temperature heatmap with a toggle between maximum and minimum temperatures.
- **Level 2:** Daily maximum and minimum temperature trends displayed as mini line charts for the last 10 years.
- Interactive tooltips and temperature color legends.

## How to Run

1. Clone or download this repository.
2. Open a terminal in the project directory.
3. Start a local server using Python:

   ```bash
   python3 -m http.server 8000
   ```

4. Open `http://localhost:8000` in your browser.

## Technologies

- HTML, CSS, JavaScript
- D3.js v7

## Data Source

`temperature_daily.csv` – Hong Kong daily temperature dataset provided with the assignment.
